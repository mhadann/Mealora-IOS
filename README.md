# Mealora
A modern mobile application that allows users to discover restaurants, purchase meal packages, and redeem meals using QR code scanning.

---

## Features
- Browse restaurant offers and meal packages
- Purchase and manage meal packages
- Activate packages directly in the app
- Scan QR codes to redeem meals at restaurants
- Clean and intuitive UI built with SwiftUI

---

## Tech Stack
- Swift & SwiftUI
- REST API (GitHub-hosted JSON)
- MVVM Architecture
- AVFoundation (QR code scanning)
- Git & GitHub
